# Kaivalya Law — Website Redesign

Premium editorial website for **Kaivalya Law**, a law firm based in Prayagraj, Uttar Pradesh. Visual design is original.

## Story

Global positioning → Philosophy → Expertise → People → Proof → Insights → Contact

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or `npm run dev -- -p 3001` if that port is busy).

## Pages

- `/` Homepage
- `/about` About
- `/people` Team directory
- `/people/[slug]` Lawyer profile
- `/expertise` Practice index
- `/expertise/[slug]` Practice area
- `/insights` Publications
- `/insights/[slug]` Article
- `/pro-bono` Pro bono
- `/gallery` Editorial gallery
- `/contact` Contact
- `/privacy` `/disclaimer`

## Notes

- Team portraits use architectural photography with initials — not stock faces attributed to named lawyers.
- Client “logos” are typographic industry marks from published work, not invented corporate logos.
- Gallery images are architectural, not photographs of the firm’s offices.
- Enquiry form confirms locally; write to **manish.tiwari@kaivalyalaw.com** or **akhand.tripathi@kaivalyalaw.com**.
